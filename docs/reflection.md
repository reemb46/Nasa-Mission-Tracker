What I learned in this project was how to use GitHub to manage a project. This included how to create issues, label them, assign them, create different branches, commit, and do pull requests to merge branches into the master. I also learned that dividing a project into many different issues makes it easier to track and organize your work. 

My biggest challenge throughout this project was learning how branches, commits, and pull requests work together. This was due to the fact that I had never used GitHub before. However, it was enjoyable watching the NASA Mission Tracker come together piece by piece when I finished and merged features. If I could continue to work on this project I would add more NASA missions, pictures, filters, and interactive features to the website.
