# NASA Mission Tracker

## Project Idea

NASA Mission Tracker is a simple website that allows users to explore information about different NASA space missions. The website will display missions such as Artemis II, the Perseverance Rover, and the James Webb Space Telescope. Each mission will include basic information such as its destination, status, and purpose.

The goal of this project is to make information about NASA missions easy to understand and accessible. It can help users learn more about space exploration and NASA's work through a simple and organized website.

## Technologies and Tools Used

- HTML - used to create the structure and content of the website.
- CSS - used to design and style the website.
- JavaScript - used to add simple interactive features.
- GitHub - used for version control, project planning, branches, issues, and pull requests.

## How to Run or Use the Project

1. Download or clone the NASA Mission Tracker repository.
2. Open the project folder on your computer.
3. Locate the `index.html` file.
4. Open `index.html` in a web browser.
5. Browse the NASA missions displayed on the website.
6. Use the mission filters to view missions based on their status.
